# UI primitives

| Primitive         | Selector                                | Snippet                                                                                                                                                                                                                               |
| ----------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `AppButton`       | `button[appButton]`, `a[appButton]`     | `<button appButton variant="secondary" size="sm">…</button>` (variants: primary, secondary, ghost, inverse, danger; sizes: sm, md, lg; `[loading]="form().submitting()"` = spinner over the label, keep `[disabled]` too)             |
| `AppChipGroup`    | `app-chip-group`                        | `<app-chip-group label="Alergeni" size="sm" [options]="allergens" [(value)]="selected" />` (Aria multi-select listbox; option: `{ key, label }`; sizes sm, md, lg)                                                                    |
| `AppDialog`       | `app-dialog`                            | `dialog.open(MyDialog)`; template: `<app-dialog title="Obriši stavku">…<button appButton dialog-actions>Obriši</button></app-dialog>`                                                                                                 |
| `AppField`        | `app-field`                             | `<app-field label="Cena" controlId="price" hint="…" suffix="RSD" [field]="form.price"><input appInput variant="price" id="price" [formField]="form.price" /></app-field>`                                                             |
| `AppInput`        | `input[appInput]`, `textarea[appInput]` | `<input appInput [formField]="form.name" />` (variants: text, price)                                                                                                                                                                  |
| `AppMenu`         | `app-menu`                              | `<app-menu label="Nalog" [items]="items" (selected)="run($event)" />` (item: `{ value, label, icon? }`, icon is a Lucide component; trigger `icon`, `look="nav"` = sidebar row, `compact` = icon only, `above` = opens upwards)       |
| `AppPattern`      | `app-pattern`                           | `<app-pattern [seed]="venue.name" [cols]="4" [rows]="2" [fluid]="true" />` (seed is app data; `cell`, `big`, `fluid`; fluid needs a size-container parent)                                                                            |
| `AppSegmented`    | `app-segmented`                         | `<app-segmented label="Tema" [options]="options" [(value)]="theme" />` or `[formField]`                                                                                                                                               |
| `AppSelect`       | `app-select`                            | `<app-field label="Valuta" controlId="currency" [field]="form.currency"><app-select controlId="currency" [options]="options" [formField]="form.currency" /></app-field>` (Aria combobox + listbox; option: `{ value, label, hint? }`) |
| `AppSearch`       | `app-search`                            | `<app-search label="Traži objekat" [(value)]="query" />` (search box of a list's `.filters` bar; filters as you type, Esc clears; match with `matchesQuery` from `shared/text/fold.ts`)                                               |
| `AppSearchPicker` | `app-search-picker`                     | `<app-search-picker label="Dodaj stavku" [options]="options" (picked)="add($event)" />` (Aria editable combobox; filters without diacritics, emits each pick and clears, for adding several things)                                   |
| `AppSwitch`       | `input[type=checkbox][appSwitch]`       | `<label><input type="checkbox" appSwitch [formField]="form.available" /> Dostupno</label>`                                                                                                                                            |
| `ConfirmDialog`   | `app-confirm-dialog`                    | `dialog.open<boolean, ConfirmDialogData>(ConfirmDialog, { data: { title, body, confirm } }).closed` → `true` to go ahead                                                                                                              |
| `AppToaster`      | `app-toaster` + `Toaster`               | once in `App`; `inject(Toaster).show($localize\`…\`)`after a save that navigates away (tone`success`default,`danger`); errors that need fixing stay inline as `.alert`                                                                |

**Row actions:** group a row's buttons in an Aria toolbar so the row is one tab stop and arrow keys move between them: `<div class="row" ngToolbar [softDisabled]="false" [attr.aria-label]="actionsLabel(name)"><button appButton ngToolbarWidget …>`. `softDisabled=false` keeps `[disabled]` buttons really disabled.

**States (patterns, no component):** page or form message `<p class="alert" role="alert">` (`data-tone` success / warning / info, default danger); loading `<p class="loading" role="status" i18n="@@common.loading">Učitavanje…</p>` (fades in after `--loading-delay`, so fast loads never flash); empty list `.empty-state` with a Lucide icon, `.empty-state__title`, `.empty-state__body`; tabs `ngTabList.tabs` > `ngTab.tab`; floating panels `.popover` + `cdkConnectedOverlayTransformOriginOn=".popover"`.
