# Stat

KPI vrednost: mono labela, krupan broj, promena u odnosu na prethodni period.

**Delovi:** `r-stat` > `r-stat__label`, `r-stat__value`, `r-stat__delta` (`--up` / `--down`).

**Potrošač daje:** vrednost formatiranu sa tačkom za hiljade, period poređenja u tekstu promene.

- Promena uvek ima znak (+/−) i reč za period — boja ne nosi značenje sama.
