# Badge

Status u jednoj do dve reči, mono VELIKIM SLOVIMA sa tačkom u boji tona.

**Tonovi:** `r-badge--success` (dostupno, objavljeno), `--warning` (uskoro nestaje), `--danger` (nema, greška), `--info` (nacrt), `--accent` (novo, preporuka lokala), bez modifikatora = neutralno. `r-badge--plain` uklanja tačku.

**Potrošač daje:** tekst statusa. Boja nikad ne nosi značenje sama — reč je obavezna.
