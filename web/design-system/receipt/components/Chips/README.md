# Chips

Horizontalna traka kategorija u javnom meniju; aktivna kategorija je u boji lokala.

**Struktura:** `r-chips` (horizontalni skrol, bez trake za skrol) > `r-chip`; aktivni dobija `aria-current="true"`.

**Potrošač daje:** listu kategorija, aktivnu kategoriju (scroll-spy), sticky poziciju (`z-sticky`) na vrhu menija.

- Visina `control-md` (40px), razmak `space-2`.
- Jedna reč po čipu kad god je moguće.
