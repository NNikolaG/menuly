# Tag

Tiha mono oznaka za činjenice o stavci: gramaža, zapremina, alergeni, dijetalne oznake.

**Potrošač daje:** kratak tekst. Alergene piši kodovima ili punim imenom, dosledno u celom meniju.

- Tag nije interaktivan; za filtere koristi Chip.
- Najviše 4 taga po stavci u javnom meniju; ostalo na detalju stavke.
