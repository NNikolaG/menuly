# Dialog

Modalni prozor za potvrdu ili kratku formu; jedini element sa senkom `shadow-lg`.

**Delovi:** `r-dialog` > `r-dialog__head` (`r-dialog__title`), `r-dialog__body`, `r-dialog__foot` (akcije desno, glavna poslednja).

**Potrošač daje:** naslov kao pitanje, posledicu u telu, dugmad sa glagolom koji ponavlja radnju („Obriši stavku“, ne „Da“); overlay (`z-overlay`) i fokus zarobljen u dijalogu.

- Na telefonu dijalog postaje sheet odozdo.
