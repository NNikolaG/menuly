# Switch

Prekidač za stanje koje se primenjuje odmah, bez dugmeta „Sačuvaj“ — npr. da li je stavka dostupna danas.

**Potrošač daje:** `<input type="checkbox" role="switch">` unutar `<label class="r-switch">` i tekst `r-switch__label` koji opisuje uključeno stanje.

- Za izbor u formi koja se čuva dugmetom koristi checkbox, ne prekidač.
- Cela labela je meta dodira (min. `touch-min`).
